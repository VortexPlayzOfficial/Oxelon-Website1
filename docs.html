Oxelon Documentation

Learn how to configure, manage, and use Oxelon to protect and operate your Discord community.

Getting Started

Oxelon is a Discord management and protection bot designed for communities that need moderation, logging, security, and server management tools.

1. Add Oxelon

Invite Oxelon to your Discord server using the official invitation provided on the Oxelon website.

2. Configure Permissions

Oxelon requires the permissions necessary for the features enabled in your server. Avoid granting permissions that are not required for your intended configuration.

3. Configure Logging

Configure a dedicated logging channel so important moderation and security events can be recorded.

Moderation

Oxelon provides moderation tools that can be used by authorised members of your staff team.

  • Warnings
  • Timeouts and mutes
  • Kicks
  • Bans
  • Message management
  • Role management
  • Channel controls

Security

Oxelon includes configurable security features designed to help server staff respond to suspicious activity and protect their communities.

  • Raid response tools
  • Server lockdown functionality
  • Security logging
  • Moderation records
  • Configurable staff permissions

Logging

Server administrators can configure logging channels for relevant events. Logs may contain information such as Discord user IDs, usernames, actions performed, timestamps, and server information.

Support

If you encounter a problem with Oxelon, contact the Oxelon support team through the official support community. Include relevant error messages and information about the affected feature.
