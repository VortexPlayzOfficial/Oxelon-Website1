OXELON SECURITY

Security

Oxelon is designed to give Discord communities practical tools for responding to moderation and security incidents.

Protection Features

  • Raid response tools
  • Moderation controls
  • Server lockdown functionality
  • Configurable staff permissions
  • Security event logging

Logging

Security and moderation events can be recorded in administrator-selected Discord channels. Logs help authorised staff understand what happened during an incident.

Responsible Disclosure

If you discover a security issue affecting Oxelon, please report it privately to the Oxelon development team rather than publicly sharing exploit details.

Do not publicly disclose active vulnerabilities

Provide enough information for the development team to reproduce and investigate the issue safely.

Security Limitations

No Discord bot can guarantee complete protection against every attack, abuse attempt, outage, or third-party platform issue. Server owners remain responsible for configuring their server and responding to incidents.
